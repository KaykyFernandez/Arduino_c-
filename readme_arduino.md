# Arduino C++ Classroom Activities
Repositório com atividades práticas usando Arduino em sala de aula, programadas em C++.

## 📘 Sobre
Este repositório contém os arquivos de atividades feitas em sala de aula com Arduino, utilizando a linguagem C++. O objetivo é registrar os exercícios, experimentos e projetos realizados durante as aulas para referência futura.

## 🧪 Conteúdo
- Sketches de Arduino (arquivos `.ino`, `.c++`, etc)  
- Exemplos de interação com sensores, displays e outros módulos Arduino  
- Atividades com foco em lógica de programação, manipulação de I/O, timers, displays (ex: LCD)  
- Estrutura típica: pasta `arduino/`, arquivo `LCD.c++` etc.  

## 🚀 Como usar
1. Clone este repositório:  
   ```bash
   git clone https://github.com/KaykyFernandez/Arduino_c-.git
   ```  
2. Entre na pasta:  
   ```bash
   cd Arduino_c-
   ```  
3. Abra o projeto em Arduino IDE ou editor compatível.  
4. Conecte sua placa Arduino, selecione a porta e placa no IDE, compile e carregue o sketch.  

## 🎯 Ferramentas & Requisitos
- Arduino IDE ou outro ambiente compatível com Arduino  
- Placa Arduino (ex: Uno, Nano, etc)  
- Cabos, sensores ou displays conforme os exercícios  
- Conhecimento básico em C++ e programação embarcada  

## 💡 Por que este repositório?
- Registro organizado das atividades de laboratório e práticas de sala de aula  
- Facilita revisões, réplica de experimentos e uso como base para novos projetos  
- Permite compartilhar códigos exemplares com outros colegas ou no portfólio
